# Notebooks

This directory contains Jupyter notebooks for interactive exploration of the theory.

## Planned contents

- **01_wis_basics.ipynb** — introduction to WIS, incidence graphs, and cycle criteria.
- **02_uod_computation.ipynb** — computing the Universal Optimality Defect for small systems.
- **03_information_bounds.ipynb** — verifying the Lipschitz and quadratic bounds numerically.
- **04_three_level_theorem.ipynb** — exploring the structure of critical points.
- **05_comparative_geometry.ipynb** — comparing UOD geometry with Fisher, Hellinger, and $\chi^2$.
