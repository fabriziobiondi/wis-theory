# Code

This directory contains the computational companion for the monograph.

## Planned contents

- **Apollonian framework** — Python implementation of the core WIS algorithms (mismatch operator, UOD computation, three-level solver).

- **Benchmark scripts** — scripts to reproduce the figures and numerical experiments in the monograph.

- **Example configurations** — YAML/JSON configurations for running experiments on AES S-box, geo-indistinguishability, browser fingerprinting, and differential privacy.

## Status

This directory is currently a placeholder. The code will be released alongside future versions of the monograph.
