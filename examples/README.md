# Examples

This directory contains standalone example configurations and data files.

## Planned contents

- **AES S-box** — incidence matrix and multiplicity data for the AES S-box (the main running example).
- **Browser fingerprinting** — anonymised browser configuration vectors (from Panopticlick-style studies).
- **Geo-indistinguishability** — coordinate grids and Laplacian noise parameters.
- **Differential privacy** — database query workloads and $\varepsilon$ values.
- **Mix networks** — anonymity set configurations.
- **Side-channel** — power trace templates and key hypotheses.

## Status

This directory is currently a placeholder. Examples will be added in future releases.
