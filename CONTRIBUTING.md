# Contributing

Thank you for your interest in this work.

## Reporting issues

- **Mathematical errors**: open an issue with the specific page, theorem/lemma number, and a description of the problem.
- **Typographical errors**: pull requests fixing typos are welcome.
- **Missing references**: if a known result is used without citation, open an issue with the bibliographic reference.

## Pull requests

1. Fork the repository.
2. Make your changes.
3. If you modify LaTeX source, verify the document compiles with `pdflatex + bibtex + 2x pdflatex`.
4. Submit a pull request with a clear description.
